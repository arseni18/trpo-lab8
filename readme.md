# Телефонная станция

Учебный проект по дисциплине «Введение в разработку программного обеспечения» (БНТУ), вариант 5.

## Описание

Консольное приложение на C# (.NET), моделирующее работу телефонной станции:

- администратор подключает абонентов и назначает им номера телефонов;
- абонент выбирает одну или несколько предоставляемых услуг;
- абонент оплачивает счёт за разговоры и услуги;
- администратор просматривает список неоплаченных счетов и блокирует абонента.

## Состав проекта

| Файл | Назначение |
|------|------------|
| `Program.cs` | текстовое интерактивное меню, ввод и проверка данных |
| `Person.cs` | базовый класс: фамилия, имя, отчество |
| `Administrator.cs` | администратор: подключение и блокировка абонентов, неоплаченные счета |
| `Subscriber.cs` | абонент: номер телефона, выбор услуг, счета, оплата |
| `Service.cs` | услуга: название и стоимость за месяц |
| `Bill.cs` | счёт за разговоры и услуги |

## Меню программы

1. Создать администратора (затем подключить абонента)
2. Показать список абонентов
3. Выбрать услугу для абонента
4. Выставить счёт абоненту
5. Оплатить счёт
6. Показать неоплаченные счета
7. Заблокировать абонента
8. Выход

## Запуск

- Visual Studio: открыть проект и нажать Ctrl+F5.
- Терминал: перейти в папку проекта и выполнить `dotnet run`.

## Ветки

- `master` – основная ветка с исходной версией проекта;
- `dev` – ветка разработки, в которую добавляются все новые изменения.
